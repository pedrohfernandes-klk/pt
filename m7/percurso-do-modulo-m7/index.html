7. Lírica Pessoana_A palavra do módulo é «fingir». Fingir é mentir?

O caminho são as lições, pela ordem: jogas os itens e fazes as duas atividades de cada uma. No fim de cada unidade, enfrentas o chefe. O que fizeres fica marcado neste aparelho; podes saltar para onde a aula estiver.
