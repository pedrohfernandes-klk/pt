Cortar é escolher o que o outro não vê.

Os fotogramas de Inês Pereira são intertítulos de cinema mudo; os outros são desenhos a traço nossos. Nunca imagens dos filmes nem do documentário. O que escreves vai para o caderno; o telemóvel só guarda as cenas feitas.
