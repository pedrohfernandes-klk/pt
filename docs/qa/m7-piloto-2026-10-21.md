## Referência para os restantes módulos

Aplicar quando o texto o justificar: leitura → observação precisa → exemplo de interpretação com prova e limite → exercício que obriga a decidir → comparação → transferência. Um esquema só é útil se tornar visível uma relação; uma etiqueta de gramática ou de estilo deve ajudar a explicar um efeito. Aproximar obras exige explicitar diferenças. As interpretações abertas precisam de critérios e pistas, sem uma única resposta artificialmente imposta.

Este é um piloto concretizado nestas duas lições, não uma revisão editorial integral dos nove módulos.
